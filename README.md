# btc-mempool-bot

Telegram-бот на NestJS + TypeScript. Следит за движением средств на биткоин-адресах через [mempool.space API](https://mempool.space/docs/api).

## Что умеет

- **Подписка на адреса** (с необязательной меткой). Уведомления приходят:
  - как только транзакция появляется в мемпуле (0 подтверждений);
  - при первом подтверждении;
  - если неподтверждённая транзакция пропала из мемпула (RBF / вытеснение).
- **🔍 Баланс / транзакция сейчас**: баланс адреса с последними транзакциями или статус транзакции по txid (подтверждения, комиссия, прогноз попадания в блок).
- **⏱ Время с последнего блока**: сколько прошло с момента добычи, майнер, средний интервал.
- **📋 Мои адреса**: список подписок, проверка, отписка и суммарный баланс.
- Все суммы показываются в BTC, USD и RUB. Курс USD берётся из mempool.space, рубль — пересчётом по курсу ЦБ РФ (`RUB_RATE_URL`).
- **⚙️ Настройки** (`/settings`): основная валюта для балансов и сумм транзакций (BTC, USD или RUB) показ остальных валют после неё и часовой пояс для дат (UTC по умолчанию, UTC+2 Калининград, UTC+3 Москва). Настройки свои у каждого чата.

## Запуск

```bash
npm install
cp .env.example .env   # указать BOT_TOKEN
npm run build
npm start
```

Для разработки: `npm run start:dev`. Тесты: `npm test`.

Нужен Node.js 22+ (используются встроенные `fetch` и `WebSocket`).

## Как это устроено

```
src/
  config/     конфигурация из env (@nestjs/config)
  mempool/    REST-клиент (очередь запросов, ретраи на 429) и WebSocket-клиент
  storage/    подписки и известные транзакции в JSON-файле
  watcher/    отслеживание изменений → событие watcher.tx
  bot/        grammy: меню, команды, тексты сообщений
```

Источник истины — REST `GET /address/:addr/txs`. Бот сравнивает статусы транзакций с запомненными и из разницы
выводит события. Внеочередную проверку запускают:

1. WebSocket `track-addresses`: мгновенно, как только транзакция появилась в мемпуле или попала в блок;
2. новый блок из WebSocket: перепроверяются адреса с неподтверждёнными транзакциями;
3. периодический опрос (`POLL_INTERVAL_SEC`) на случай, если WebSocket отвалился.

Поэтому обрыв WebSocket не приводит к потере уведомлений: они просто придут с задержкой до одного интервала опроса.

## Команды

| Команда | Описание |
|---|---|
| `/start` | меню и справка |
| `/sub <адрес> [метка]` | подписаться |
| `/unsub <адрес>` | отписаться |
| `/list` | мои адреса |
| `/check <адрес или txid>` | проверить сейчас |
| `/block` | сколько прошло с последнего блока |
| `/settings` | валюта сумм и часовой пояс |

Можно просто прислать адрес или txid в личку, и бот его проверит.

## Замечания

- В группах кнопки меню работают, только если у бота выключен privacy mode (`/setprivacy` в @BotFather). Команды работают всегда.
- Публичный mempool.space ограничивает частоту запросов. Если адресов много, увеличьте `POLL_INTERVAL_SEC` / `REQUEST_GAP_MS`
  или укажите свой инстанс mempool в `MEMPOOL_URL`.
- Время блока ставит майнер, оно может отличаться от реального на несколько минут. Бот дополнительно показывает, когда сам узнал о блоке.
